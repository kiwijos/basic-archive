# Cantaloupe serves the original scans by Image id, from an image we build

The assumption in the spec held: an Image's id is the public IIIF identifier and, with no prefix or suffix, the object key in the `masters` bucket, so `S3Source` with `BasicLookupStrategy` needs no delegate script and no lookup table. It was checked first, on the cluster, against a real upload. Keys have no file extension, and Cantaloupe works out the format from the Content-Type stored on upload (catalog-api sets it), so extension-less keys cost nothing. Cantaloupe holds the `cantaloupe` Garage key, which can only read `masters`.

There is no official Cantaloupe image and the community ones are unpinned third parties, so `services/cantaloupe/Dockerfile` builds from the official 5.0.7 release zip, checked against its published SHA-256, on a pinned Temurin 21 JRE as a non-root user, and is published like the other images. Things found on the way, so they are not found again: Cantaloupe reads a setting from the environment under its key in capitals with punctuation turned into underscores and no prefix (`S3Source.endpoint` is `S3SOURCE_ENDPOINT`, not `CANTALOUPE_S3SOURCE_ENDPOINT`); `info.json` reports the address the visitor used because Traefik forwards it, so no host is configured anywhere; `max_pixels` of 10 megapixels clamps `full/max` and refuses an explicit full-size request of a larger scan with 403, so no one can ask the decoder for a whole 54-megapixel blueprint, while tiles are far smaller and unaffected.

Large JPEG and PNG files must be decoded whole to cut a tile, TIFF can be read in chunks. Cantaloupe therefore keeps each original on local disk after its first request and every tile it makes (`emptyDir`, safe to lose). Measured on a 9000 by 6000 pixel TIFF through the Ingress, tiles take 45 to 170 ms cold and 12 to 16 ms warm. Tiles are marked `public` with a week's lifetime because an Image never changes under its id. The Ingress for `/iiif/3` is separate and carries a Traefik rate limit per client address (100 requests a second, bursts of 300), well above a person zooming and far below a script; `make iiif-limits` shows it working. Traefik's open-source edition has no response cache, so caching is done by the browser (headers) and Cantaloupe (disk).

The viewer is OpenSeadragon 6.1.1, loaded only on a Document page. On start it adds one inline `<style>` rule (hiding the focus outline on touch devices), which the page's Content-Security-Policy would block; even an empty `<style>` element is blocked, so the policy allows exactly that rule by its hash, and the browser test fails on any policy violation if an upgrade changes it. Allowing `unsafe-inline` for styles was rejected. The zoom proof is a large synthetic ship lines plan drawn by `scripts/make_blueprint.py` and dedicated to the public domain (CC0), so no one else's scan has to be cleared; real public-domain plans are for the seed slice.
